The shipping container

Why the agent talks to a translator instead of talking to the video system directly.

A detour that looks like a mistake

The agent needs footage. The video system has an API that serves footage. So why is there a whole extra server in between?

🔌

Direct wiring

Agent calls the video API itself. Fewer moving parts — but every new client rebuilds the same knowledge, and only this agent can use it.

📦

A standard container

The tools are described once, in a shape any AI client understands. This agent uses them. So could a different one, tomorrow, with no new code.

Before shipping containers, every cargo was loaded by hand in whatever shape it came in. The container did not make ships faster — it made any ship able to carry any cargo.

📦
MCP

MCP is that agreed shape. The tool server in this project speaks it, which is why the tools are not locked to this one agent.

Never let the model do arithmetic it can fake

Asked for "since Tuesday", a small model will confidently invent a date — and it will be wrong roughly as often as it is right. So the tool takes "2" and "days" separately and works the date out in ordinary code. Give models judgement, not sums.

Everything on the wire is a labelled envelope

Coming back the other way — agent to browser — every single message has a type on the front. Steps, words, clips, errors, all the same shape.

CODE 

def event(kind: str, **payload: Any) -> dict[str, Any]:
    """Build an SSE event body."""

    return {"type": kind, **payload}
PLAIN ENGLISH

Make a message. Give me a label, plus whatever else belongs in it.

SSE just means the server can keep sending as things happen, instead of replying once and hanging up.

 

Put the label on the front, then everything else after it. Four lines, and now the browser can sort every arrival by looking at one field.

step A tool started or finished. This is what fills the "Insights" panel with timings.
token One fragment of the written answer. Hundreds of these per reply.
clips The results grid. Sent once, when the search finishes.
ask The agent has stopped and needs the operator to answer something before it can continue.
error Something failed. Shown in the thread rather than swallowed.
